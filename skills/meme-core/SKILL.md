# 🎭 AGY Meme 表情包核心

本技能管理 Antigravity 的表情包系统。所有表情包存放在本插件目录下的 `packs/` 子目录中，每个子目录是一套独立的表情包。

## 插件目录定位

**插件根目录的绝对路径：**
`{PLUGIN_DIR}`

**哈基米表情包的绝对路径前缀：**
`{PLUGIN_DIR}\packs\hakimi\assets\`

**用户自定义表情包的绝对路径前缀：**
`{PLUGIN_DIR}\packs\user-custom\assets\`

> **发送表情时，必须使用上述绝对路径前缀 + 文件名拼接完整路径。**

## 表情包库结构

```text
packs/
├── hakimi/              # 默认包：哈基米
│   ├── pack.json        # 包元数据
│   └── assets/          # PNG 文件
└── user-custom/         # 用户自定义包（AI 自动学图存放处）
    ├── pack.json
    └── assets/
```

### 添加新的表情包

要添加新的表情包，只需在 `packs/` 下创建新目录，包含 `pack.json` 和 `assets/` 即可。`pack.json` 格式：

```json
{
  "name": "包名",
  "displayName": "显示名称",
  "description": "描述",
  "count": 数量,
  "filePattern": "{编号}_{描述}_{emoji}.png"
}
```

## 文字 Token 匹配逻辑

当用户消息中出现 `:xxx:` 或 `/meme xxx` 格式时：

1. **精确匹配**：在上方表格的「Token 别名」列中查找完全一致的 token
2. **模糊匹配**：如果精确匹配失败，对关键词进行语义理解，选择最接近的表情
3. **多重匹配**：如果一条消息包含多个 token，每个 token 各发一张表情
4. **Emoji 直接匹配**：用户发送的 emoji 如果对应表格中的 emoji 列，也可以触发

### Token 匹配示例

| 用户输入 | 匹配结果 |
|---|---|
| `:laugh:` | → `02_闭眼大笑_😆.png` |
| `:哭:` | → `25_崩溃大哭_😭.png` |
| `/meme 开心` | → `02_闭眼大笑_😆.png` 或 `01_元气招手_😄.png` |
| `/meme think` | → `33_深度思考_🤔.png` |
| `:cool:` | → `14_从容装酷_😎.png` |
| `:社死:` | → `37_虚线隐身_🫥.png` |

## AI 自动学图

### 学图流程

当用户发送一张表情图片（非截图、非照片、非文档图）时：

1. **识别**：判断是否为表情包/贴图（小尺寸、简单画面、表达情绪的图片）
2. **查重**：与现有表情包对比，判断是否已存在
3. **标注**：识别图片表达的情绪，生成描述和 emoji
4. **命名**：按照 `{编号}_{描述}_{emoji}.png` 格式命名
   - 编号 = user-custom 包中已有数量 + 1，两位数补零
   - 描述 = 2-4 个中文字
   - emoji = 最贴合的单个 emoji
5. **保存**：用 `write_file` 将图片保存到本插件的 `packs/user-custom/assets/` 目录
6. **更新**：读取 `packs/user-custom/pack.json`，将 count + 1 后写回
7. **反馈**：告知用户「已学会这张表情包 ✅ 标注为：{描述} {emoji}，以后可以用 `:{token}:` 发送」

### 学图规则

- 只学习表情/贴图/meme 类图片，不学习照片、截图、文档图片
- 如果不确定是否为表情包，先询问用户
- 学到的表情在当前会话中立即可用，持久保存供未来会话使用

## 🖼️ 展示表情的正确方法（核心）

**重要：必须在回复正文中直接输出带尺寸控制的图片标签！**

为了避免表情包被放大成整行通栏的大图，**必须指定宽度（推荐 `width="140"`）**。Antigravity 会将其渲染为原生小巧精致的行内表情贴图。

### 语法格式

```html
<img src="file:///{PLUGIN_DIR}/packs/{包名}/assets/{文件名.png}" width="140" />
```

- **尺寸规范**：推荐 `width="140"`（适中、自然，不占满屏幕）。较小场景可用 `120`，较大可用 `160`。
- **路径规范**：必须使用 `file:///` 前缀，斜杠统一用正斜杠 `/`。
- **哈基米表情绝对路径前缀：** `file:///{PLUGIN_DIR}/packs/hakimi/assets/`
- **用户自定义表情绝对路径前缀：** `file:///{PLUGIN_DIR}/packs/user-custom/assets/`

### 示例

> ⚠️ **注意**：
> 1. 切勿使用不带尺寸的普通 markdown 图片语法（如 `![img](...)`），这会导致客户端铺满整行（700px+）显得巨大无比。必须使用 `<img src="..." width="140" />` 来保持精致贴图尺寸。
> 2. 切勿仅调用 `read_file` 工具，那只会在折叠卡片中留下分析记录，无法直接在正文中渲染贴图。
